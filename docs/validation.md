## 当前版本

当前后端为 Node.js / TypeScript，采用 Fastify、SQLite、本地文件、Sharp 与数据库任务表轮询。本机原型包括图片上传、设计资产、复刻与试戴任务、规则裁剪、参考图拼排及结果存储接口。

正式前端、门店扫码系统、账号与会话隔离、门店试点及付费业务尚无完成证据。现有 React 交互原型使用预设图片、计时器和页面状态展示流程，没有连接当前后端。

## 视觉质量如何验收

已整理的评测维度包括款式与饰件保持、甲型长度、甲片数量、五指对应、手部保持和佩戴自然度。需要分别记录每个手指的结果，并保留原款、原手、生成图、Prompt 与参数。

当前尚未冻结统一质量分母：

- 早期 70 条用例为评测设计资产，执行记录为 0，不能记作 70 次真实评测或通过。
- 当前 V1.3 的 20 组固定视觉回归仍待冻结，不能作为已执行量。
- 29 项历史问题为问题索引，不能作样本数或已关闭缺陷数。
- 不同模型服务、辅助分割、透明抠图和 2D 合成是独立实验，没有统一横评条件。

## 商品视觉 Skill 的验证范围

`muse10-nail-visuals` 的公开资料包括固定 1200×1500 画布、L1–L5 / R1–R5 十指清单、素材角色拆分、阶段 Prompt、背景校验脚本及图库规则。

背景检查用于画布、共享背景的 RGB 与 alpha；不评估饰件保持、指位正确或手部解剖。商品手模佩戴图也不能替代消费者本人手图试戴验收。当前没有后端直接调用该 Skill 的证据。
